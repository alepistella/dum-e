# Robot configuration

Robot-specific settings and development workarounds live here. They are
separate from the Gazebo and RViz graphics setup.

- [Workarounds](workarounds/README.md): scope, validation and rollback.
- [Cartographer](workarounds/cartographer/README.md): a conservative 2D
  loop-closure search candidate and the procedure for validating it on Dum-e.

An experiment validated on TurtleBot3 is not automatically a validated Dum-e
hardware configuration. Each profile states where it was measured.
